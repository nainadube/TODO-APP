 Todo List App
A simple and minimalist Todo List application built using HTML, CSS, and JavaScript.

Features

- Add tasks
- View tasks
- Delete tasks

Technologies Used

- HTML
- CSS
- JavaScript

Purpose

This project was built to practice fundamental web development concepts including DOM manipulation, event handling, and user interaction.

Future Improvements

- Mark tasks as completed
- Save tasks using localStorage
- Edit tasks
- Search and filter tasks
